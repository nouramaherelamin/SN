IMPORTANT
---------
These are visual UI mockups and handoff specifications, not a fully coded website.
The PNG previews are flattened reference images. The PDFs describe how to separate assets
and implement clickable elements as real HTML/CSS components.

The currently prepared set has a numbering gap: Scene 07 — العاصفة is not included as a
separate screen pack in the available source files. Add that screen before treating this
archive as a final, complete 11-scene production handoff.

For the interactive experience:
- Keep text, buttons, hotspots, cards, and popups as real UI elements (not baked into images).
- Export background art separately from character/object PNGs with transparent backgrounds.
- Use responsive layout and large tap targets for children.
- Keep the approved child astronaut and Oppy designs, facial features, and original palette consistent.
- Use the supplied reference animation only as interaction/motion inspiration; do not copy its artwork.

The uploaded GIF reference is included as Reference_Animation.gif.
